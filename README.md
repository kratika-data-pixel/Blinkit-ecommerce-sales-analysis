# Blinkit E-Commerce Sales Analysis

## 📊 Project Overview

This project is an Excel-based E-Commerce Sales Analysis Dashboard created using Blinkit dataset.

The project focuses on data cleaning, data validation, analysis, KPI creation, Pivot Tables, and interactive dashboard development.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- VLOOKUP
- Excel Formulas
- Slicers
- Data Cleaning
- Data Analysis

## 📁 Dataset

The project uses multiple datasets:

- Orders
- Order Items
- Products
- Customers

## 📌 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Total Customers

## 📈 Analysis

The dashboard includes:

- Monthly Sales Trend
- Sales & Profit by Category
- Sales & Profit by Brand
- Sales by Payment Method
- Sales by Delivery Status

## 🎯 Dashboard

The Excel dashboard provides interactive filters for:

- Year
- Month
- Category
- Brand
- Payment Method
- Delivery Status
